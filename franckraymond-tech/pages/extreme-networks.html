04

Migration VoIP Avaya

Dans le cadre du renouvellement de l'infrastructure réseau de la Mairie de La Madeleine, les commutateurs historiques Avaya sont remplacés par des équipements Extreme Networks (Série 5320/5420). Lors de la bascule initiale, les téléphones IP Avaya n'ont pas réussi à récupérer leur configuration réseau via DHCP, entraînant une interruption de service.

Différences Avaya vs Extreme Networks

Caractéristique Switch Avaya (Legacy) Switch Extreme (EXOS)
Découverte VoIP Automatique (ADAC) - Mécanismes propriétaires Manuelle (LLDP-MED) - Configuration explicite requise
Gestion VLAN Port Port-based flexible, VLAN voix taggué auto Stricte Tagged/Untagged - Data Untagged, Voix Tagged
Protocole Découverte ADAC ou TLVs propriétaires Avaya Standard LLDP-MED (Media Endpoint Discovery)
Syntaxe CLI Nortel legacy (config vlan <id> ports add...) EXOS modulaire (configure vlan <nom> add ports...)

Conclusion : Les switchs Avaya simplifiaient la connexion des téléphones grâce à des automatismes propriétaires. Avec Extreme, il faut configurer le standard LLDP-MED pour obtenir le même résultat.

05

Configuration LLDP-MED

Configuration validée sur switch Extreme 5320 en version EXOS permettant aux téléphones Avaya de découvrir automatiquement leur VLAN.

A. Configuration des VLANs

# 1. Création des VLANs
create vlan "Data" tag 1     # VLAN par défaut pour les PC
create vlan "Voix" tag 2     # VLAN dédié à la téléphonie

# 2. Configuration du port utilisateur (Téléphone + PC)
configure vlan Data add ports 2 untagged  # PC en VLAN 1
configure vlan Voix add ports 2 tagged    # Téléphone en VLAN 2

B. Configuration LLDP-MED (Coeur de la solution)

# 1. Activer LLDP sur les ports
enable lldp ports 2

# 2. Annoncer les capacités MED
configure lldp port 2 advertise vendor-specific med capabilities

# 3. Indiquer le VLAN Voix au téléphone
configure lldp port 2 advertise vendor-specific dot1 vlan-name vlan Voix

# 4. Appliquer la politique QoS (DSCP 46 = Prioritaire)
configure lldp port 2 advertise vendor-specific med policy application voice vlan Voix dscp 46

# 5. Gestion alimentation PoE via LLDP
configure lldp port 2 advertise vendor-specific med power-via-mdi

C. Configuration PoE et Physique

# Activer le PoE
enable inline-power ports 2

# Forcer 100Mbps Full-Duplex (stabilité anciens postes Avaya)
configure ports 2 auto off speed 100 duplex full

D. Configuration Uplink

# Port reliant le switch au coeur de réseau (port 13)
configure vlan Data add ports 13 untagged  # Natif/Management
configure vlan Voix add ports 13 tagged    # Voix taggué

Bilan des Tests en Lab

Alimentation : Téléphone alimenté via PoE (~1.6W)
Découverte VLAN : LLDP-MED bascule auto sur VLAN 2
Connectivité PC : PC branché derrière téléphone OK (VLAN 1)
Mise à jour : Téléphone télécharge firmware et redémarre
DHCP Voix : En attente config relais DHCP production

Prérequis Production

Configurer IP Helper (Relais DHCP) sur VLAN Voix
Vérifier Option DHCP 242 (MCIPADD) pour serveur Avaya
