Infrastructure Windows Server

AD + DHCP + DNS + GPO

J'ai déployé une infrastructure Windows Server complète avec Active Directory, DHCP, DNS et stratégie de groupe (GPO) pour gerer les utilisateurs et les postes du domaine.

Active Directory DHCP / DNS
01

Contexte du projet

Dans le cadre du module R5, j'ai déployé une infrastructure Windows Server complète pour le domaine ordiglobal.local. Mon objectif etait de mettre en place Active Directory avec une structure OU, des utilisateurs métiers, des GPO de restriction et les services DHCP/DNS.

Cadre : Windows Server avec les roles AD DS, DHCP, DNS et GPMC. Structure organisationnelle avec separation IT/RH et politiques de groupe différenciées.

Roles déployés

AD-Domain-Services DHCP DNS GPMC

Structure

OU OrdiGlobal OU IT / RH GPO Restrictions Scope DHCP
02

Pourquoi cette solution ?

Choix de Windows Server avec AD

J'ai choisi Windows Server avec Active Directory pour sa maturité et son adoption massive en entreprise. AD offre une gestion centralisée des identités, des stratégies de groupe (GPO) puissantes et une intégration native avec les services DHCP/DNS. Cette solution est le standard dans les environnements professionnels, ce qui en fait une compétence essentielle à maîtriser pour un technicien systèmes et réseaux.

Active Directory & OUs

Structure des OUs

J'ai créé une arborescence d'unites organisationnelles pour structurer le domaine par service.

  • OU=OrdiGlobal
    • OU=Users
      • OU=IT ← GPO-IT-Restrictions
        • alice.it
        • bob.it
      • OU=RH ← GPO-RH-Restrictions
        • claire.rh
        • david.rh
    • OU=Computers
    • OU=Groups
      • GRP_IT_Users
      • GRP_RH_Users
    • OU=ServiceAccounts

Utilisateurs et Groupes

J'ai créé les utilisateurs métiers et les groupes de sécurité correspondants.

GRP_IT_Users : alice.it, bob.it
GRP_RH_Users : claire.rh, david.rh
OU RH avec GPO
LinkedGroupPolicyObjects visible
OU IT avec GPO
LinkedGroupPolicyObjects visible
Membres des groupes
GRP_IT_Users et GRP_RH_Users
05

Strategies de groupe (GPO)

GPO-IT-Restrictions

J'ai créé une GPO pour les utilisateurs IT qui desactive la commande Executer.

# Registre applique HKCU\Software\Microsoft\Windows\CurrentVersion\Policies\Explorer NoRun = 1

GPO-RH-Restrictions

J'ai créé une GPO pour les utilisateurs RH qui desactive l'accès au Panneau de configuration.

# Registre applique HKCU\Software\Microsoft\Windows\CurrentVersion\Policies\Explorer NoControlPanel = 1
06

DHCP & DNS

Configuration DHCP

J'ai installe et configure le role DHCP avec un scope pour le réseau 172.20.10.0/28.

Serveur DHCP autorise dans AD
Scope: 172.20.10.5 - 172.20.10.10
Option 003 Routeur: 172.20.10.1
Option 006 DNS: 172.20.10.12
Option 015 Domaine: ordiglobal.local

Configuration DNS

J'ai configuré la zone DNS pour le domaine ordiglobal.local.

# Zone principale ordiglobal.local # Enregistrement À ad.ordiglobal.local -> 172.20.10.12 # Test résolution Resolve-DnsName ad.ordiglobal.local # Resultat: 172.20.10.12
DHCP - Serveur autorise, Scope actif, Options
Get-DhcpServerInDC, Get-DhcpServerv4Scope, Get-DhcpServerv4OptionValue
