BloodHound (Audit AD)

Audit d’Active Directory pour identifier les chemins d’attaque.

Actions Preuves
01

Contexte & objectifs

Dans le cadre de l'amélioration de la sécurité de l'infrastructure Active Directory, j'ai realise un audit complet à l'aide de BloodHound. Cet outil permet de cartographier les relations entre les objets AD (utilisateurs, groupes, machines) et d'identifier les chemins d'attaque potentiels qu'un attaquant pourrait exploiter pour escalader ses privilèges jusqu'au Domain Admin.

Problématique : Comment identifier et corriger les failles de configuration dans Active Directory avant qu'elles ne soient exploitees ?
