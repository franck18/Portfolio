01

Before starting

The need and my role

The need

Build a realistic environment for learning how to operate services over time: deployment, updates, certificates, monitoring, backups and incident resolution.

My role

I personally administer the infrastructure. I handle the Linux systems, containers, network, security and monitoring.

Maintain services without a dedicated operations team.
Isolate containers and preserve persistent data.
Renew certificates and limit exposed services.
Detect resource issues and retain usable backups.
02

Why I chose this approach

The chosen solution

Containerised services behind a single Nginx entry point

Docker Compose groups services, networks and volumes; Nginx centralises routing by subdomain; Let's Encrypt certificates secure web access. This structure reduces scattered configuration while keeping direct Linux administration.

Internal and external DNS resolution is provided for hosted services.
Nginx acts as a reverse proxy and routes subdomains.
Docker Compose manages services with isolated networks and persistent volumes.
Let's Encrypt provides certificates with automated renewal.
UFW filters exposed services and SSH access uses keys.
Monitoring covers CPU, memory, disk and network use.

05

Looking back

Limits and improvements

Security and operation

  • Network exposure is limited with UFW.
  • SSH access uses keys and is supplemented by Fail2Ban.
  • Web services use TLS encryption.
  • System logs are centralised and analysed as described in the initial project.

What I would improve

  • The number of services, availability and operating period have not yet been quantified.
  • RPO/RTO objectives and restoration results still need to be measured.
  • Configuration automation is not yet demonstrated through an Ansible repository or equivalent.

Skills demonstrated

  • Administer Linux systems over time.
  • Structure containerised services and their dependencies.
  • Secure access and manage TLS certificates.
  • Monitor, back up and maintain an independent infrastructure.
