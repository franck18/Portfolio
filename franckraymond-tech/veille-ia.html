IA & Automatisation

Comment l'IA et l'automatisation changent le quotidien des admins systèmes — outils, usages concrets et retours d'expérience.

LLM Locaux Automatisation
01

Pourquoi cette Veille ?

Les outils IA comme ChatGPT ou les modèles locaux (Ollama) commencent à changer la façon dont on travaille en IT — génération de scripts, aide au diagnostic, documentation automatique. Mais envoyer des données sensibles vers le cloud pose des problèmes de confidentialité, d'où l'intérêt des solutions locales.

En parallèle, automatiser les tâches répétitives avec des outils comme Ansible fait gagner un temps considérable et réduit les erreurs humaines.

02

LLM Locaux

Un LLM local tourne directement sur ta machine ou ton serveur — pas de connexion internet, pas de données envoyées à l'extérieur. Utile en entreprise quand on veut de l'assistance IA sans exposer les données internes.

Open Source

Ollama

Outil en ligne de commande pour faire tourner des LLM localement. Supporte Llama 3, Mistral, CodeLlama… Installation simple, API intégrée.

# Installation et utilisation
curl -fsSL https://ollama.ai/install.sh | sh
ollama run llama3
Open Source

LM Studio

Interface graphique pour télécharger et faire tourner des LLM. Parfait pour débuter sans passer par le terminal.

GUI Windows/Mac/Linux
Tendance

Open WebUI

Interface web style ChatGPT pour Ollama. Plusieurs utilisateurs peuvent s'en servir en même temps, avec historique des conversations. RAG intégré. Déployable en Docker.

Docker Self-hosted

Modèles populaires en 2024-2025

Llama 3 (Meta) : polyvalent, très performant
CodeLlama : spécialisé développement
Mistral 7B : léger et efficace
Phi-3 (Microsoft) : petit mais puissant
03

Automatisation IT

Au lieu de configurer les serveurs à la main, on écrit des fichiers qui décrivent ce qu'on veut — et l'outil s'en charge. Moins d'erreurs, gain de temps, et tout est traçable dans Git.

Ansible

Ansible se connecte aux machines via SSH et exécute des tâches définies dans des fichiers YAML. Pas besoin d'installer quoi que ce soit sur les serveurs cibles. Pratique pour configurer plusieurs machines d'un coup.

# Exemple playbook Ansible
- name: Installer Apache
  hosts: webservers
  tasks:
    - name: Install httpd
      apt: name=apache2 state=présent

Terraform

Terraform permet de créer et gérer des ressources cloud ou locales depuis des fichiers de config. Avant d'appliquer, il montre exactement ce qu'il va faire — pratique pour éviter les mauvaises surprises.

Multi-cloud State management

CI/CD & GitHub Actions

Automatiser les tests et déploiements dès qu'on pousse du code sur Git. Plus besoin de déployer à la main — le pipeline s'en charge. GitHub Actions ou GitLab CI permettent de mettre ça en place simplement.

GitLab CI GitHub Actions
04

Impact sur les Métiers IT

Opportunités

  • Assistance au diagnostic et dépannage
  • Génération de scripts et documentation
  • Analyse de logs automatisée
  • Chatbots support niveau 1

Défis

  • Nécessité de valider les réponses IA
  • Risques de sécurité (injection prompt)
  • Dépendance aux outils
  • Formation continue requise

Ce qu'il faut apprendre

  • Savoir formuler de bonnes questions à l'IA
  • Automatiser avec Ansible, scripts PowerShell/Bash
  • Python pour les tâches utilitaires
  • Ne pas faire confiance aveuglément aux réponses IA
